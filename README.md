# DSH Connect Tabbit

面向 DSH 的第三方 Tabbit 插件，接入 Tabbit 国内版与国际版账号、模型和工具调用。

网关直接内置在插件进程中，随 DSH 启动与关闭；无需单独安装 Python、Docker，也无需手动启动 `tabbit2api` 服务。

> 本项目为独立社区插件，与 Tabbit 无隶属或背书关系。账号能否使用、模型目录与额度均受 Tabbit 当前服务状态和账号条件影响。

## 功能

- 国内版、国际版分别维护账号池。
- 支持官方登录、凭据或文件导入；部分 Windows 环境支持导入本机 Tabbit 浏览器登录态。
- 账号凭据保存在本机，内置网关运行时使用内存副本。
- 上游提供时读取模型目录、周期额度、模型消耗倍率和每日签到状态。
- 把模型工具请求转换为 DSH 可执行的调用，并把真实工具结果返回模型。
- 显示输入、输出、累计 Token；优先采用官方回传值，没有官方用量时明确标记本地估算。
- 支持流保活、有限次数的任务续接和长上下文；失败或不完整的上游结果会明确报错。

更多说明见[架构](docs/architecture.md)、[数据处理与限制](docs/privacy.md)和[更新记录](CHANGELOG.md)。

## 安装和使用

1. 在 DSH 插件管理器中安装 `dsh-connect-tabbit`，然后重新加载 DSH。
2. 打开 **设置 → 插件 → dsh-connect-tabbit**。
3. 在对应版本账号池中登录 Tabbit 或导入账号。
4. 在 DSH 中选择可用的 Tabbit 模型；需要执行桌面或其他任务时启用相应工具。

插件包需要 Node.js `22.19+` 或 `24+`，并使用 DSH 提供的 peer dependencies。国内版和国际版账号不能互相通用。

## 数据与使用边界

- 账号记录保存在 `~/.dsh/plugins/dsh-connect-tabbit/accounts.json`，系统支持时使用受限文件权限。
- 模型请求会发送到所选 Tabbit 版本。超过网页输入限制的长上下文可能通过 Tabbit 文档附件流程上传，并受 Tabbit 自身的数据保留政策约束。
- 官方未返回 Token 时显示的是本地文本估算，不是官方 tokenizer、扣费明细或人民币账单，也不会记入 DSH 货币费用账本。
- 模型工具调用仍依赖模型能力与上游协议。插件会校验调用内容，但不会把模型的普通文字当作工具执行证据。
- 账号过期、额度用尽、模型或协议变化、上游停服仍可能中断任务。重连次数有限。
- 0.4.0 尚未完成国际版真实账号调用验证；国际版需要独立账号。

## 开发

```sh
npm test
npm pack --dry-run
```

自动测试使用模拟服务，不需要 Tabbit 账号。公开仓库不包含会访问本机账号或浏览器配置的实时验证脚本。
