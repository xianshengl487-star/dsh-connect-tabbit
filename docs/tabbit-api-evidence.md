## 推断（inferred）

- 官方用 `100 - usage_percentage` 表示剩余周期百分比；插件依此显示剩余值。显示倍率反映相对额度消耗，不能仅凭倍率计算单次请求固定扣减。
- 网页接口接受单个文本内容，完整 OpenAI 历史通过保留角色的文本协议投影，并非官方提供的 OpenAI 原生消息 API。
- 工具桥接依赖指定模型遵守外部协议；即使同一模型通过测试，上游仍可能拒绝或改变路由。未知工具、缺参数或空回复不会被当成已执行。

## 尚未知（unknown）及边界

- 官方终止事件未观察到 token 用量或人民币账单。0.3.0 起另提供明确标记的本地文本 Token 估算，不作为官方用量或账单；不把 SDK 补出的全零计数当成真实免费账单。周期额度、模型倍率是已核验的官方消耗展示口径。

## 0.2.0 内置网关与 492（2026-10-21）

已观察到：实际失败模型为 `glm-5-3-flashx`，两次失败请求分别是 44 / 47 条消息、95 个工具、300,593 / 305,116 字符；原始 SSE `error` 的代码为 492，说明为“欢迎使用 Tabbit 浏览器”。同一账号与模型的短请求成功回复 OK，纯合成长请求复现 492。v3 返回 HTTP 429 时，正文仍含 492，不能直接当成账号限流。

静态证据：`page-0f72bae065ccbffb.js` 的模块 22959 定义 `2e4` 上限，发送前检查 `plainText.length` 并报告 `too-long`。相同脚本模块 1635 / 1786 展示官方附件流程：

1. `POST /proxy/v0/cos/presigned-upload-url`，`file_category: document`、文件名、MIME 与字节数。
2. 向返回的 COS 预签名地址 PUT 文件，使用文件 MIME，不发送 Tabbit Cookie。
3. `POST /api/v0/cos/complete-upload`，传入 `file_id` 和当前会话 ID。
4. 聊天引用 `{type: file, metadata: {file_id}}`，正文低于输入框上限。

真实验证：官方预签名接口返回 200；COS 上传、登记与 v3 引用可用。44,261 字符的纯合成附件被模型完整识别。只将指令放在附件中时，模型可能只分析文件而不继续用户任务，因此正文另行保留当前用户请求和外部工具协议；完整消息和工具定义仍全部保存在附件，未进行历史裁剪。

DSH 原装 SDK → shim → **插件内置 Node 网关** → 官方 Tabbit 已验证默认模型，以及 GLM-5.3-FlashX 的 95 工具 / 超长合成上下文工具往返。工具调用 `open_page`，浏览器 `edge`，URL 为 B 站；收到模拟成功结果后继续回答，未重复调用，账号 active / errors 0。仅测试协议，不代表真实浏览器执行。

内置实现随 npm 包的 `lib/embedded/` 一起发布，没有 Python、临时目录源码、用户绝对路径或外部进程依赖。默认随机回环端口与进程内密钥；关闭时中止请求、清理服务与内存账号副本。单元测试覆盖鉴权、区域隔离、停止清理、完整上下文上传、COS 不携带 Cookie、错误不生成假成功以及 492 不冷却账号。国际版服务启动可验证，但当前没有有效国际版账号，不声称认证模型调用成功。

## 0.2.1 真实 DSH 界面回归

使用 Electron 的本机 CDP 连接控制真实 DSH 窗口，在界面新建“Tabbit插件回归测试”会话，模型 GLM-5.3-FlashX，未通过脚本替模型启动测试软件。

- 当前用户消息：实际回复“收到，当前消息已收到”。
- 浏览器调用：`computer_observe` 真实返回 B 站网页目标、URL 与标题。此路径遵循本机浏览器技能的隔离浏览器优先规则，不能当成本机 Edge 已打开。
- 系统调用：DSH 实际运行 `pwsh`，以 `Start-Process` 启动记事本、计算器和本机 Edge。首次进程检查因旧程序名与截断未确认全部窗口，模型随后按真实结果修正检查：Notepad 窗口存在，msedge 窗口标题包含 B 站，CalculatorApp 存在且 ApplicationFrameHost 窗口标题为“计算器”。

- 实际缺陷：Agent Loop 使用 `prepareCall().stream()`，绕过了插件直接 `stream()` 上的未知用量过滤。0.2.1 两个入口共用过滤，回归测试覆盖 Agent Loop 的真实入口。

界面轨迹、软件窗口证据和测试报告保存于 `output/tabbit-normal-use-20261021/`。本机 `dsh-browser-workflow` 的目标选择规则也单独调整为尊重明确指定的已安装浏览器；系统启动与图形交互分别检查能力，保留默认隔离浏览器策略。
