# 发布文案

**标题**：DSH 里接入 Tabbit：插件内置网关、账号池、工具调用与 Token 用量说明

**简介**：

介绍第三方插件 `dsh-connect-tabbit`：在 DSH 中登录或导入 Tabbit 国内版 / 国际版账号，读取可用模型与周期额度，通过 DSH 执行工具调用，并查看官方用量或明确标记的本地 Token 估算。

插件把兼容网关内置在 DSH 进程中，不需要单独启动 Python、Docker 或固定端口的 tabbit2api 服务。视频里的设置卡片为功能示意，实际模型目录与额度以 Tabbit 当前接口为准。

注意：插件不隶属 Tabbit；账号过期、额度、上游变化和服务状态仍会影响使用。Token 本地估算不是官方账单。0.4.0 版本尚未完成国际版真实账号调用验证。
